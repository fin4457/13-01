### Задание 2

Проведите сканирование Metasploitable в режимах SYN, FIN, Xmas, UDP.

Запишите сеансы сканирования в Wireshark.

Ответьте на следующие вопросы:

- Чем отличаются эти режимы сканирования с точки зрения сетевого трафика?
- Как отвечает сервер?

*Приведите ответ в свободной форме.*

### Решение 2  

1. SYN-сканирование (-sS). Nmap отправляет пакет с флагом SYN (запрос на открытие соединения). Реакция открытого порта: Хост отвечает пакетом SYN-ACK. В ответ Nmap сразу отправляет RST (сброс), обрывая соединение до его завершения. Реакция закрытого порта: Хост отвечает пакетом RST. Реакция фильтруемого порта (Firewall): Хост ничего не отвечает, либо отправляет ICMP-ошибку (destination unreachable).  
2. FIN-сканирование (-sF). Метод опирается на стандарт RFC 793. Трафик от Nmap: Отправляет пакет только с флагом FIN (запрос на закрытие соединения), без предварительного открытия этого соединения. Реакция открытого порта: Согласно RFC, открытый порт должен игнорировать такой некорректный пакет и ничего не отвечать. Реакция закрытого порта: Хост отвечает пакетом RST.
3. Xmas-сканирование (-sX). Трафик от Nmap: Отправляет пакет сразу с тремя флагами: FIN, PSH, URG. Реакция открытого порта: Как и в FIN-сканировании, по стандарту RFC открытый порт игнорирует этот пакет и молчит. Реакция закрытого порта: Хост отвечает пакетом RST.
4. UDP-сканирование (-sU). Работает на уровне протокола UDP, который не гарантирует доставку и не использует флаги соединений (SYN/ACK/RST). Трафик от Nmap: Отправляет пустой UDP-пакет на целевой порт. Реакция открытого порта: Если порт открыт, приложение на той стороне может ответить своим UDP-пакетом. Чаще всего приложение просто игнорирует пустой пакет и ничего не присылает. Nmap классифицирует это как open|filtered. Реакция закрытого порта: Хост возвращает ICMP-сообщение об ошибке: «Type 3, Code 3» (Destination Unreachable / Port Unreachable).
